# Prompt 설계 테스트용 코드

## 프로젝트 소개
이 페이지는 **프롬프트 설계 테스트용 코드**를 정리한 README입니다.  
주요 목적은 OpenAI API 기반 기능을 테스트하고, 프롬프트 입력 방식과 JSON 실험 데이터를 활용하여
응답 결과를 확인하는 것입니다.

---

## 핵심 요약
- 본 코드는 **프롬프트 설계 및 테스트용**으로 작성되었습니다.
- JSON 파일은 **실험용 입력 데이터** 또는 테스트 케이스 용도로 사용됩니다.
- 실제 배포용 서비스라기보다는, **동작 검증 / 프롬프트 실험 / 구조 테스트**에 초점을 둔 코드입니다.
- 환경 변수 파일인 `.env` 는 **보안상 제외**하였습니다.

---

## 사용 목적
이 프로젝트는 아래와 같은 목적을 위해 사용됩니다.

1. 프롬프트 입력 구조 테스트
2. 사용자 입력과 시스템 프롬프트 구성 방식 실험
3. JSON 기반 테스트 데이터 적용
4. OpenAI API 응답 형태 확인
5. 기능별 결과 비교 및 설계 검증

---

## 파일 설명
### 주요 파일
- `README.md`  
  프로젝트 설명 문서입니다.

- `*.py`  
  프롬프트 테스트 및 실행용 파이썬 코드입니다.

- `*.json`  
  실험용 입력 데이터 파일입니다.  
  테스트 상황에 따라 다른 입력값을 넣어 결과를 비교하는 용도로 사용합니다.

---

## JSON 파일 안내
이 프로젝트에 포함된 JSON 파일은 **실험용 파일**입니다.  
즉, 실제 서비스 운영 데이터가 아니라 아래 목적에 사용됩니다.

- 입력 예시 구성
- 테스트 케이스 분리
- 공격/이벤트/질문 시나리오 확인
- 프롬프트 결과 비교

따라서 JSON 파일의 내용은 실행 및 검증을 위한 샘플/실험 데이터로 이해하면 됩니다.
