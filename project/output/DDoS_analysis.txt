[유사 로그 요약 및 패턴 해석]
다음은 검색어 ‘DDoS’ 관련 유사 로그 현황과 패턴 해석입니다. 사실과 추론을 구분해 기술합니다.

사실(로그·통계 기반)
- 유사 로그 건수: 4건
- 유형/위험도: DDoS 4건, High 2건, Critical 2건
- 파일 분포: incident_sample.csv 4건
- 발생 시각 범위: 2026-03-20 09:12:00 ~ 2026-03-24 17:25:00
- 반복되는 수치형 특징
  - flow_packets_s: 1750 ~ 2500 (평균 2037.5)
  - flow_bytes_s: 240,000 ~ 330,000 B/s (평균 282,500 B/s)
  - init_fwd_win_bytes: 650 ~ 920 (평균 792.5)
- 노트 패턴: “HTTP 요청 급증”, “외부망 패킷 폭주”, “대량 요청 반복” 등 반복 문구 확인
- 프로토콜 정보: 제공 통계에선 명시적 프로토콜 분포 없음(불명)

반복되는 특징의 의미(사실에 근거한 해석)
- 짧은 기간(약 4일)에 동일 유형(DDoS) 알림이 연속 발생했고, 위험도가 High~Critical로 높게 표시됨.
- 초당 패킷/바이트가 모든 건에서 높은 구간으로 일관되게 관찰됨(pps 1.7k~2.5k, B/s 240k~330k).
- init_fwd_win_bytes가 좁은 범위(650~920B)에 집중되어 동일/유사한 통신 스택 또는 도구군에서 발생했을 가능성을 시사.
- 노트에 HTTP 트래픽 급증과 대량 요청 반복이 명시되어, 애플리케이션 계층 요청 플러딩을 시사.

왜 이상 패턴으로 볼 수 있는지(추론)
- 동일 기간 내 반복적이고 일관된 고(高) pps/Bps 패턴이 다건 식별되어 정상 사용자 행위보다는 공격적 트래픽 패턴(플러딩)에 가까움.
- 평균 bytes/packet이 대략 100~190B 수준으로 추정되어(= bytes_s / packets_s 범위) 페이로드가 작은 플러딩(예: 짧은 요청 반복, 네트워크/세션 제어 패킷 위주) 특성과 부합할 가능성.
- init_fwd_win_bytes가 좁은 구간에 수렴하는 점은 동일 툴킷/봇 집단에 의한 트래픽일 가능성을 높임.
주의: 내부 정상 트래픽의 기준선(baseline)과 프로토콜/세션 세부 정보가 없어, L3/L4 기반(예: SYN/UDP)인지 L7(HTTP) 기반인지 단정은 불가. 다만 노트의 “HTTP 요청 급증”은 L7 플러딩 정황을 보강하는 간접 근거임.

MITRE ATT&CK 해석(후보)
- 후보 1: T1499.003, Application Exhaustion Flood, Tactic: Impact
  - 근거: “HTTP 요청 급증”, “대량 요청 반복”이라는 노트와 L7 트래픽 과부하 정황.
- 후보 2: T1498.001, Direct Network Flood, Tactic: Impact
  - 근거: 높은 pps가 일관되게 관찰되어 네트워크 레벨 플러딩 가능성도 배제 불가(프로토콜 불명으로 확정 어려움).

추가 점검 가이드(실무)
- 트래픽 급증 확인
  - 동일 시간대 pps/Bps가 평소 대비 급증했는지, 급증 구간의 지속 시간과 동시 다발성(동시 세션 수)을 확인.
- 소스 특성 분석
  - Source IP 분포(분산도, ASN/국가), User-Agent/HTTP 메서드/URI 패턴, 쿠키/헤더 유사도 등으로 동질 집단 여부 판별.
- 프로토콜/계층 식별
  - L3/L4(SYN/UDP) vs L7(HTTP/HTTPS) 구분을 위해 패킷 샘플 또는 플로우 메타데이터의 프로토콜/포트/플래그 분석.
- 방어 정책 점검
  - WAF 룰·Rate Limit·CAPTCHA·자동화 탐지, L4 방화벽/ACL, CDN/스크러빙 적용 여부와 차단/우회 지표 확인.
- 영향 범위 파악
  - 대상 서비스 응답지연, 오류율, 자원 사용률(CPU/메모리/스레드) 변화를 모니터링하여 실제 장애 징후와 상관관계 확인.
- 증거 보강
  - 패킷 캡처(PCAP)와 서버/애플리케이션 로그(예: Web Access Log)의 동시간대 상관 분석으로 기법 특성 확정.

요약
- 4건의 DDoS 관련 유사 로그가 짧은 기간에 발생했으며, 고(高) pps/Bps와 반복적 문구(HTTP 급증/대량 요청)가 관찰되어 플러딩 계열 공격 정황이 강합니다.
- 프로토콜 세부가 없어 확정은 유보하되, MITRE ATT&CK 기준으로는 T1499.003(애플리케이션 고갈 플러딩) 또는 T1498.001(네트워크 플러딩)이 유력 후보입니다.
